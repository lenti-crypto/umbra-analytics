# Umbra — Market Data Analytics Case Study

Portfolio case study describing analytical work with real-time crypto market data in Umbra.

## Role

**Data Analyst & Analytics Engineer**

## Focus

- Multi-exchange price, spread, and funding-rate validation
- SQL-based data quality checks
- Detection of stale, missing, duplicated, and anomalous records
- Dashboard analysis and investigation reporting

## Case study versions

- `index.html` — English
- `index-ua.html` — Ukrainian

## Tools

SQL, PostgreSQL, dashboards, data validation, reporting
